# Menu Customizer 3.2.4

Restores the previous menu-font baseline and removes the Compact, Bold and Clean variants. MENU FONT now offers Native and Emerald.

The Emerald battle option uses the actual imported Emerald normal/narrow font sheets, widths, shadows, palettes, window templates and battle artwork, rendered through ported Gen1Recomp presentation code. Move names use the original two-column positions, the native arrow, original PP placement and the single-line TYPE/name. Generation 1/2 adapters provide live battle values to the Emerald healthboxes and bottom panels. Ruby/Sapphire and FR/LG use Emerald presentation without changing their battle rules. Your selected Menu Border is preserved.

**Requires an imported Pokemon Emerald ROM in Gen1Recomp.** Reimport Emerald if the cache is old. No Emerald ROM or extracted battle graphics are bundled in this update. Fully restart after installing. KIM1025 1.7.26 already delegates move styling to this mod and does not need an update.
